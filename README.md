# Semantic HTML5 & Accessible Component Architecture

An accessible, multi-page enterprise dashboard built using HTML5, CSS3, and JavaScript, focusing on semantic structure, accessible forms, keyboard navigation, and responsive design.

## Project Overview

This project demonstrates the structural foundation of an enterprise dashboard using semantic HTML5 elements and accessibility best practices.

## Features

- Multi-page dashboard layout
- Semantic HTML5 structure
- Accessible navigation with clear page indicators
- User management data table
- Add New User form with HTML validation
- Accessible user details modal dialog
- Keyboard support for modal interactions
- Responsive layout for desktop and mobile screens
- W3C HTML validation screenshots

## Technologies Used

- HTML5
- CSS3
- JavaScript
- W3C HTML Validator

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the dashboard, user management form, modal dialog, and other pages.

## Accessibility Features

- Semantic landmarks such as `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- Explicit form labels associated with their input controls
- Fieldsets and legends for grouping related form fields
- Native HTML form validation
- Accessible table headings and caption
- Keyboard-operable modal dialog
- Visible keyboard focus indicators
- Responsive mobile layout

## Validation

All four HTML pages were checked using the W3C HTML Validator. The validation screenshots are available in the `validation-screenshots/` directory.

## Screenshots

The `screenshots/` directory contains desktop, mobile, form validation, and modal dialog screenshots.
